친구들이 링크로 함께 참여하는 시즌 웹 놀이 브랜드. 운영자 김이나 · moodnight@kakao.com

### 성탄맨션 기획 (확정)
- 방 주인에게 4층 × 3호 = **12집 고정** 맨션 한 동. 링크 받은 친구가 빈 집에 입주
- 입주할 때 고르는 것: 호수, 창문 불빛(호박빛·촛불빛·장밋빛·풀빛·달빛), 창에 비치는 그림자(파티, 이불 쓰고 컴퓨터, 창가에 기대기, 고양이랑 쉬기, 뭔가 끓이는 중, 혼자 춤추기), 베란다 소품, 집 안 아바타 포즈, 말풍선 편지(60자)
- 창문을 누르면 집 안 장면 + 아바타 위 말풍선. **편지는 바로 읽을 수 있음** (크리스마스 개봉은 산타 몫)
- 공개 범위는 **입주한 친구가 집마다** '모두 보기' / '주인만 보기'
- 못 들어온 친구는 **벽보**(글만, 40자, 닉네임 비우면 익명): "방빼!!", "나도 들어가고 싶었는데" 등
- 집주인 관리: **입주자 퇴거**(퇴거된 닉네임은 재입주 불가, 실서비스는 기기 기준도 추가), **벽보 떼기**, 산타와 같은 신고 → 자동 숨김
- 1층 왼쪽 **산타의 선물가게**(반짝이는 간판) → 산타 서비스로 연결. 산타의 선물가게는 '산타의 선물가게'로 이름 변경 예정
- 1층 오른쪽 **루돌프네 양말공장**: 창문에 뿔로 양말 뜨는 루돌프 그림자(코 깜빡임). 지금은 장식만, 기능은 공개 후
- 체험판: `/mansion/demo/` (예시 친구 7명, 저장 안 됨, '빈 집 다 채워 보기'로 꽉 찬 상태 확인)
